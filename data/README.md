# Data acquisition

Third-party texts and text-bearing derivatives are not included. Check each source's licence before use. Run scripts from the repository root.

The commentary parser `scripts/run_parse.py` expects these OpenITI texts in the parent directory of the repository: `0676Nawawi.MinhajFiSharhMuslim.JK000137-ara.txt`, `0855BadrDinCayni.CumdatQari.Shamela0005756-ara1.txt`, and `1081Mazandarani.SharhUsulKafi.Shia001174Vols-ara1.txt` (OpenITI identifier `1081MuhammadSalihMazandarani.SharhUsulKafi.Shia001174Vols-ara1`). Obtain the corresponding versions from [OpenITI](https://github.com/OpenITI/RELEASE). The parser writes `data/babs/{nawawi,cayni,mazandarani}_babs.json`; these contain commentary text and are excluded.

The OpenITI v2025.1.9 [manifest](openiti/corpus_manifest.json) records exact URIs, URLs, hashes, input paths and output names for Ṣaḥīḥ Muslim, Lisān al-ʿArab, al-Nihāya, and Sunni and Imami rijāl works. Place raw files under `data/openiti/raw/`, `data/lexica/raw/`, and `data/rijal/raw/` as specified; parsed files include `data/openiti/muslim_raw.json`, `data/openiti/muslim_clusters.json`, `data/lexica/{lisan,nihaya}_entries.json`, and `data/rijal/{sunni,imami}_rijal.json`. See `scripts/parse_openiti.py` and `scripts/parse_muslim.py` for parsing functions.

The project also expects Bukhari and al-Kāfī collection derivatives `data/bukhari_raw.json`, `data/kafi_raw.json`, and samples `data/{bukhari,kafi,muslim}_sample.json`. These source collections and text-bearing samples are excluded. The exact collection editions and acquisition procedure for Bukhari and al-Kāfī are not recorded in the supplied manifests; ask the author before attempting an exact reconstruction. `scripts/build_isnad_sample.py` describes the sample format and seed.

The [Qur'an manifest](quran/corpus_manifest.json) records Tanzil v1.1 and Quranic Arabic Corpus morphology v0.4 URLs, hashes and terms. Obtain the simple-clean and Uthmani Tanzil exports and morphology file and put them under `data/quran/raw/` using the names in the manifest. The derived `data/quran/quran_roots.json` contains verse text and is excluded. Follow the manifest's conversion description to reconstruct it.

Sample and derived files can embed source text even when generated by the code. Keep them private unless their redistribution terms permit release.

## Short excerpts in this repository

Test fixtures, example strings in `scripts/` and `hermeneutics/`, and quotations in `RESULTS.md` contain short excerpts (a few lines each) from premodern Arabic works: the commentaries of al-Nawawī, al-ʿAynī and al-Māzandarānī, the ḥadīth collections, and the lexica. They are taken from the OpenITI digital editions (OpenITI release 2025.1.9, DOI 10.5281/zenodo.17767721) and are included only so that the tests and examples run on real text. The full corpus texts are not included; obtain them from OpenITI under the terms of its release.
